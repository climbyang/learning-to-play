# Learning-to-Play

用家里一台常开的服务器管 LG webOS 电视的娱乐时间。每天有一定的免费时长，用完后孩子可以在电视上答数学、逻辑、英文题，答对了换时间。家长通过 Telegram 收通知，也能在手机上加时间、锁电视、远程关机。

所有控制都通过电视官方的局域网控制协议完成，跟手机遥控器 App 用的是同一个 WebSocket 接口。不用 Root，也不改固件。

> [!NOTE]
> 只在**一台 webOS 6.0 的 LG 电视（2021 年机型）**上做过实测。其他 2022 年以前的 webOS 电视大概率可以用，但没有测过。webOS 2022 及以后的电视自带"使用时间限制"，可能用不上这个项目。详见 [docs/compatibility.md](docs/compatibility.md)（英文）。

## 功能

- **记录娱乐时长**：服务器上的守护进程实时查看电视前台在运行哪个 App，并按分钟计时。主页、设置这类豁免的 App 不计时。
- **限制每日额度**：
  - 每天有免费时长和每日上限，时间快到时在电视上弹提示。
  - 支持宵禁时段和家长锁定。
  - 时间到了自动退出 App；短时间内反复打开会直接关机。
- **答题换时间**：
  - 电视上装一个答题 App，答对一题加若干分钟，加到每日上限为止。
  - 出题、判分、计时、发奖励都由服务器负责。电视端拿不到答案，重启 App 也换不了题。
- **自带题库**：
  - 共 142 个题目模板、263 道题，面向 9 到 11 岁的孩子，包括多步数学、逻辑推理和英文阅读组合题。
  - 每组阅读题做完后，还要学一两个单词：先看单词卡，再答一道检查题。
  - 图表和表格直接在电视上画出来。
- **家长用 Telegram 管理**：
  - 通知：开机、时间快用完、答对题获得时间，每天还有一份汇总。
  - 命令：查看状态、加时间、锁定或解锁、远程开机或关机、切换模式、查看答题明细、抽查题目。
- **默认观察模式**：只记录和通知，不动电视。确认统计的数字准确之后，家长在 Telegram 里切到执行模式。

## 需要准备

- **电视**：一台 LG webOS 电视，在路由器里给它固定 IP。
- **服务器**：同一局域网里一台常开的 Linux 机器，树莓派、NUC 或旧笔记本都行。需要装 Python 3.11 以上和 uv。
- **Telegram 机器人**：自己建一个，通过 @BotFather 免费创建。
- **只有用答题 App 才需要**：
  - 一个免费的 LG 开发者账号，电视上要打开开发者模式。
  - 构建 App 的电脑上要装 Node.js 和 LG 的 ares-cli。

## 开始使用

按 [docs/setup.md](docs/setup.md)（英文）的步骤操作。简单来说：

1. 把仓库克隆到服务器上，复制 `server/.env.example` 为 `server/.env`，复制 `server/config/settings.example.yaml` 为 `server/config/settings.yaml`。
2. 创建 Telegram 机器人，把机器人令牌、你的 chat id、电视的 IP 和 MAC 地址填进 `.env`。
3. 和电视配对一次：运行 `uv run ltp pair --write-env`，在电视上选"允许"。然后运行 `uv run ltp smoke` 测试连接。
4. 运行 `bash deploy/deploy.sh`，安装并启动 systemd 用户服务。
5. 可选：启用答题服务，构建答题 App 并装到电视上。

## 已知局限

- **拦不住有心绕过的孩子**：拔网线、换 Wi-Fi 或者重置电视都能绕过去。服务器发现电视断线会提醒家长，但没法强制关掉电视。真正的硬停要靠智能插座或路由器，目前还没做。
- **执行有大约 1 秒延迟**：App 是先打开、然后才被关掉，不是在启动时就被拦下。
- **开发者模式会过期**：过期后通过开发者模式装的 App 会消失。守护进程每天自动续期，续期失败会发提醒。
- **语言**：Telegram 消息是中文，答题 App 和题库是英文。
- **题库由 AI 辅助编写**：题目在 AI 帮助下编写，并由 AI 审核过。数学题的答案在加载时会重新计算核对，家长也可以在 Telegram 里抽查题目、下架有问题的题。但正式使用前，建议家长自己再看一遍。
